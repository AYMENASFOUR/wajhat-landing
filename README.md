# WAJHAT — دليل التطبيقات

صفحة عربية مستقلة (HTML/CSS/JavaScript)؛ لا تحتاج قاعدة بيانات أو حزمة بناء.

## إضافة تطبيق معتمد للنشر

1. عدّل `apps.js` فقط لإضافة عنصر جديد داخل `window.WAJHAT_APPS`.
2. الحقول المطلوبة: `id` فريد، `name` الاسم العربي، `category` التصنيف، `description` الوصف المختصر، `url` رابط HTTPS.
3. الحقول الاختيارية: `english` الاسم الإنجليزي، `icon` مفتاح الأيقونة (kitchen, factory, calculator, warehouse, clipboard, wrench, building, app)، أو `iconFile` لملف محلي مثل `icons/my-app.svg` (SVG/PNG/WebP).
4. لا تضف التطبيق قبل اعتماد إتاحته. تحقّق من الرابط والاسم والوصف والأيقونة على نسخة Preview؛ ثم اطلب موافقة المالك على الدمج والنشر.

مثال (لا تضفه إلى الدليل قبل اعتماد المنتج):

```js
{
  id: "example",
  name: "اسم التطبيق",
  english: "EXAMPLE",
  category: "الإدارة",
  description: "وصف مختصر لما يقدمه التطبيق.",
  icon: "app",
  url: "https://example.com/"
}
```

تُنشأ التصنيفات تلقائيًا؛ يدعم الدليل البحث العربي والإنجليزي، والتصفح بواقع 6 بطاقات لكل صفحة. لا تستخدم حقولًا للإعلان عن أسعار أو اشتراكات أو ضمانات لم تعتمد.
